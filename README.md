# The Robot Vacuum's Best Excuse

Entry for make.fun competition `u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214`.

`main.py` (Python 3.13, stdlib only, no network) writes one one-line excuse
a robot vacuum gives for missing a spot to `/output/entry.txt`.

## The entry

> My sensors say that dust has been there longer than my warranty, so legally it is furniture now.

96 characters.
